# Adinda Miza — Futuristic Portfolio v3

A static, GitHub Pages-ready portfolio built with HTML, CSS and vanilla JavaScript.

## Content included
The portfolio incorporates the information from the provided portfolio PDF:
- Personal/profile statement
- Education
- Training & workshops
- Web development project descriptions
- Skills
- Social/organizational experience
- Interests

It also includes the project/repository names shown in the GitHub screenshot and the current Restaurant Digital System build.

## Privacy
For a public portfolio, sensitive personal details such as full date of birth, full home address, and personal phone number are intentionally not displayed on the landing page. Keep those details in a private/application CV if needed.

## Before publishing
- Replace `#` repository links in `index.html` with the actual GitHub repository URLs.
- Replace stylized project screens with real screenshots in `assets/images/`.
- Add your preferred profile photo if desired.
- Add your LinkedIn URL.
